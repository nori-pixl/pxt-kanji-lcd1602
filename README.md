# kanji-lcd1602

LCD1602(I2C)に**ひらがな・カタカナ・漢字**を表示する micro:bit(MakeCode)用ライブラリです。
東雲フォント(パブリックドメイン)の字を、**縦2マス x 横3マス(15x16ドット)**の、線が1ドット幅の細い字で表示します。
横に縮めたり伸ばしたりしないので、線が太くなりません。

## 表示のしくみ(2つのモード)

LCD1602 の自作文字(CGRAM)は8個しかなく、縦2×横3マスの1文字は最大6個使います。

| モード | 内容 | 向いているとき |
| --- | --- | --- |
| **全部の字を切り替えて表示**(既定) | 8個に収まらない字を、いくつかの「ページ」に分けて、背景で素早く切り替える。**何文字でも同時に見える**が、そのぶん**薄くなり、ちらつく**。 | 「あいうえお」のように、何文字も並べたい |
| **1文字を固定(点滅なし)** | 入る字(たいてい1文字)だけを固定で出す。入らない字は出ない。 | 1文字をくっきり出したい |

```typescript
kanjiLCD.showKanji("あ", 0)                  // 1文字なら、既定のままでも固定表示(点滅しない)
kanjiLCD.showString("あいうえお", 0, 3)      // 5文字: 5ページを切り替えて、全部が見える
kanjiLCD.setMode(kanjiLCD.KanjiMode.Fixed)   // 点滅なしの固定表示に切り替える
kanjiLCD.showSequence("あいう", 0, 800)      // 1文字ずつ順に(どのモードでも点滅しない)
```

**ちらつきを減らす工夫**

- 空白のマスは自作文字を使わず(空白文字)、同じ形のマスは自作文字を共有します。
- ページ数が少なくなるように、使うマスの多い字から詰めます。
- ページを切り替えるときは、変わる自作文字と、変わる桁だけを、まとめて1回のI2Cで送ります。
- 1文字だけなら、ページが1つなので、背景処理は動かず、点滅しません。

**限界**(LCD1602 の仕組み上、これ以上は減らせません)

- 「あいうえお」(重複を除いて27マス)は、5ページ必要です。1回の切り替えに約270バイトのI2C通信が要り、
  micro:bit の I2C は 100kHz 固定なので、1ページ約24ms、1周で約120ms(約8回/秒)です。
- 字は1周のうち、ページ数分の1しか点かないので、5ページなら約5分の1の明るさです。
  **LCD裏の青いつまみ(コントラスト調整)を回す**と、見やすくなります。
- 字が少ないほど、ページ数が減って、ちらつきも薄さも軽くなります(2〜3文字なら、1〜2ページのことが多い)。
- 切り替えの間隔は `漢字LCD 切り替えの間隔 ○ ms`(既定 0 = いちばん速く)で変えられます。

## 漢字・ひらがな・カタカナは、文字のまま指定できます

**`pxt.json` で `"utf8": true` を指定しています。これが必須です。**

micro:bit 用の MakeCode は、既定では文字列の全角文字を、**コンパイル時に下位1バイトへ削ってしまいます**
(コンパイラの `asmStringLiteral` が `charCodeAt(i) & 0xff` をしているため)。
そのため「仙」(U+4ED9)と「ベ」(U+30D9)が、どちらも 0xD9 になって区別できず、
**漢字が別のひらがな・カタカナとして表示される**不具合が起きていました。
拡張の `pxt.json` に `"utf8": true`(「UTF-8を有効にしてコンパイルする」)を入れると、
プロジェクト全体が UTF-8 の文字列でコンパイルされ、全角文字がそのまま届きます。
(MakeCode のシミュレーターは、JavaScript の文字列をそのまま使うので、この不具合は実機でしか出ません。)

**確認のしかた**: `漢字LCDを初期化` を呼んだときに、LCD の2行目に `UTF8 OFF` と出たら、UTF-8 が効いていません。
拡張機能を一度削除して、入れ直してください(古い版が残っていると、効きません)。
ブロック `漢字LCD UTF-8が有効`(高度なブロック)でも調べられます。

```typescript
kanjiLCD.init(0x27)                          // アドレスは 0x27 か 0x3F
kanjiLCD.showKanji("仙", 0)                  // 漢字もそのまま文字で
kanjiLCD.showSequence("仙台の日曜", 0, 800)  // 1文字ずつ順に
kanjiLCD.showText("10/13", 11, 1)            // 英数字
```

数字の文字コードで指定したいときは、次も使えます。

```typescript
kanjiLCD.showCode(20185, 0)                  // 仙(固定)
kanjiLCD.showCodeText("20185 21488", 0, 3)   // 数字の文字列(ブロック用)
```

表示されない字があるときは、`漢字LCD 診断 "仙"` で調べられます(「文字列の長さ/文字コード/収録番号/単位」)。
収録番号が -1 なら、その字は収録されていません。

## 制約

- 点滅なしで同時に固定表示できる全角文字は、たいてい**1文字**です(CGRAMが8個しかないため)。何文字も出すときは、切り替え表示(既定)です。
- 文字を表示するたびに、LCD の自作文字(CGRAM)を書き換えます。表示を変える瞬間だけ、ほんの一瞬、乱れることがあります。
- 何文字も同時に、くっきり出したいときは、OLED(SSD1306など)やグラフィックLCDを使ってください。

## データの検査・作り直し

```bash
python tools/check_font.py kanjifont.ts                 # コード表・ブロック長・字形の重複を検査
python tools/add_keys.py kanjifont.ts                   # KEYS(文字で探すための並び)を作り直す。フォントを変えたら必ず実行
python tools/reblock.py kanjifont.ts 32                 # hexリテラルのブロックの大きさを変える
python tools/make_font_3x2.py 漢字15x16.ts 最初のコミットのkanjifont.ts kanafont.ts   # 細い15x16で1ファイルに作り直す
```
